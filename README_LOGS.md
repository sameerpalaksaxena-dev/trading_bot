# About the log file in this folder

`SAMPLE_OUTPUT_generated_with_mocked_api.log` shows the exact log format
the bot produces (timestamps, request, response, validation errors) for a
MARKET order, a LIMIT order, a bonus STOP_LIMIT order, and two validation
failures. It was generated by running `cli.py` against a **mocked** Binance
client, because this generation environment has no internet access to reach
Binance's servers.

**Before submitting this assignment**, delete this sample and run the two
required commands yourself against your own Binance Futures Testnet API
keys (see README.md § 2):

```bash
python cli.py --symbol BTCUSDT --side BUY --type MARKET --quantity 0.01
python cli.py --symbol BTCUSDT --side SELL --type LIMIT --quantity 0.01 --price 65000
```

This will create `logs/trading_bot.log` with real order IDs and real
responses from the Binance Futures Testnet — that is the file to submit.
